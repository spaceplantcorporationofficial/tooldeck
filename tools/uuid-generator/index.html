How to use the UUID Generator

  1. Choose v4 for fully random IDs or v7 for IDs that sort by creation time.
  2. Pick how many you need and any formatting options, then click Generate.
  3. Paste any UUID into the validator to see its version and variant (and timestamp for v7).

Frequently asked questions

What is the difference between UUID v4 and v7?

v4 is 122 bits of randomness. v7 (RFC 9562) starts with a millisecond Unix timestamp followed by random bits, so IDs sort in creation order. That makes database indexes much more efficient.

Can two UUIDs ever collide?

In practice, no. With v4 you would need to generate about 2.7 quintillion IDs to have a 50% chance of a single collision.

Is a GUID the same as a UUID?

Yes. GUID is Microsoft's name for the same 128-bit identifier format.

How many can I generate?
