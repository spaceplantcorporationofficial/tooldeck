🧩 JSON Formatter, Validator & Minifier

Paste JSON to pretty-print it, minify it, or pinpoint the exact line and column of a syntax error.

How to use the JSON Formatter & Validator

  1. Paste or type JSON into the box.
  2. Click Format to pretty-print with your chosen indentation, or Minify to strip whitespace.
  3. If the JSON is invalid you will see the exact line and column of the problem.
  4. Optionally sort object keys alphabetically, then copy the result.

Frequently asked questions

Is my JSON sent anywhere?

No. Parsing and formatting use your browser's built-in JSON engine. Nothing is uploaded, so it is safe for API keys, configs and private data.

Why is my JSON invalid?

The most common causes are trailing commas, single quotes instead of double quotes, unquoted keys, and comments. The validator shows the line and column where parsing failed.

What does minify do?

Minifying removes all unnecessary whitespace and line breaks, producing the smallest valid JSON. It is ideal for payloads, configs and storage.

Can it handle large files?

Yes. Multi-megabyte JSON documents format in milliseconds on most devices.
