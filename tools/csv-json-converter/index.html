🔄 CSV ↔ JSON Converter

Turn spreadsheets into JSON for your code, or JSON arrays back into CSV for Excel and Google Sheets.

How to use the CSV ↔ JSON Converter

  1. Paste CSV with a header row, or a JSON array of objects.
  2. Click CSV → JSON or JSON → CSV.
  3. Copy the result or download it as a .json or .csv file.

Frequently asked questions

Does it handle commas and line breaks inside fields?

Yes. It follows the RFC 4180 CSV standard: fields wrapped in double quotes can contain commas, line breaks and escaped quotes ("").

What JSON format does it produce?

An array of objects, one per row, using the header row as keys. Numbers and true/false are converted to real JSON types unless you turn that off.

How are nested JSON values converted to CSV?

Columns are the union of all keys across objects. Nested objects and arrays are written as JSON text inside the cell so no data is lost.

Is my data uploaded?

No. Conversion happens entirely in your browser, which makes it safe for customer lists and other private data.
