Frequently asked questions

What is Title Case?

Title Case capitalizes the main words of a headline. This tool keeps short words such as "a", "and", "of" and "the" lowercase unless they start the title, following common style guides.

What is the difference between camelCase and PascalCase?

Both join words without spaces. camelCase starts with a lowercase letter (myVariableName), while PascalCase capitalizes every word (MyVariableName).

When should I use snake_case or kebab-case?

snake_case is common in Python and databases; kebab-case is used in URLs, CSS classes and file names. CONSTANT_CASE is used for constants and environment variables.

Is my text stored?

No. Conversion happens entirely in your browser.
